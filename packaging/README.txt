gigafile-contextmenu インストールガイド
=========================================

【インストール】 install.bat をダブルクリックしてください。
　→ 右クリックメニュー「ギガファイル便にアップロード」と
　　送るメニュー「ギガファイル便にまとめてアップロード」が登録されます。
　→ Python などの環境は不要です（単一 exe で動作）。

【アンインストール】 uninstall.bat をダブルクリックしてください。

【つかいかた】
 ・単一ファイル: ファイルを右クリック → 「ギガファイル便にアップロード」
 ・複数ファイル: 右クリック → 送る → 「ギガファイル便にまとめてアップロード」
 　→ アップロード完了後、URL がクリップボードにコピーされます。
 　→ コンソールで Enter を押すと閉じます。

【注意】
 ・Windows 11 では「その他のオプション」(旧メニュー) 配下に表示されます。
 ・SmartScreen の警告が出る場合があります（署名なし exe の一般的挙動）。
 　その場合は「詳細情報」→「実行」で続行できます。
 ・zip 内の exe がブロック表示される場合は、exe を右クリック → プロパティ →
 　「許可する」にチェックを入れてから実行してください。
